# 고체역학: 기둥의 좌굴 시뮬레이터 (13장 Buckling of Columns)

**바로 사용하기:** https://jackwon2.github.io/buckling-simulator/

Copyright by Prof. Hyuk Lee (Hongik University, jackwon2@hongik.ac.kr,
Homepage: https://sites.google.com/view/headlab)

웹 브라우저만 있으면 설치 없이 사용할 수 있는 교육용 기둥 좌굴 시뮬레이터입니다.
축하중 P를 슬라이더로 바꾸면서 좌굴 모드 형상, 안정성, 후좌굴 거동을 실시간으로 관찰할 수 있습니다.

## 주요 기능

- **실제 거동 (안정성·후좌굴):** P < P<sub>cr</sub>에서는 외란을 주면 진동하다 복원되고(진동수 ω₀√(1−P/P<sub>cr</sub>)),
  P > P<sub>cr</sub>에서는 곧은 평형이 불안정해져 1차 모드로 좌굴합니다. 좌굴 후 형상은 대처짐 정해(elastica)로 계산합니다.
- **고유치 문제 (모드 형상):** 하중이 고유값 P<sub>n</sub> 사이의 '애매한 값'일 때, 미분방정식과 나머지 경계조건을 만족하는
  시행해가 마지막 경계조건을 어떻게 위배하는지(→ C₁ = 0) 보여주고, 1~4차 모드와 현재 하중에서의 안정성을 함께 표시합니다.
- **지지조건 비교:** 같은 기둥(같은 E, I, L)에 같은 하중을 가할 때 핀–핀, 고정–자유, 고정–핀, 고정–고정 기둥이
  유효길이 계수 K 순서대로 좌굴하는 모습을 비교합니다.
- **지지조건:** 핀–핀, 고정–고정, 고정–핀, 고정–자유, 고정–회전구속(횡이동 자유) + 위치 조절 가능한 중간 횡지지(브레이싱)
- **변곡점·유효길이:** 굽힘모멘트가 0인 점과 L<sub>e</sub> = KL 표시 (고정–자유는 아래로 연장한 가상 기둥으로 L<sub>e</sub> = 2L)
- **실제 기둥:** 1차 모드 형상의 초기 휨 e₀ (선형 증폭 e₀/(1−P/P<sub>cr</sub>), Secant 공식 비교), 응력비에 따른 항복 구간 표시
- **그래프:** P–v<sub>max</sub> 평형경로(분기선도), 특성방정식 잔차·모드별 유효강성(1−P/P<sub>n</sub>), σ<sub>cr</sub>–KL/r 곡선
- **수식:** 지배 미분방정식, 경계조건, 특성방정식, 임계하중·임계응력에 현재 값을 대입한 식 (KaTeX)
- **강의 시연 프리셋:** 임계하중·분기점, 애매한 하중, 후좌굴(자), 고차 모드(횡지지), 지지조건 비교, 초기결함, 단주

## 사용 방법

- 하중 P와 P/P<sub>1</sub>은 **슬라이더**로 대략 조절하고, 옆의 **숫자 입력칸**에 정확한 값을 입력할 수 있습니다.
  슬라이더 아래 눈금 P₁, P₂, … 를 클릭하면 그 고유값으로 이동합니다. **서서히 증가/감소** 버튼으로 하중을 자동으로 바꿀 수 있습니다.
- '실제 거동' 탭에서 기둥 그림의 **왼쪽/오른쪽을 클릭(탭)**하면 그 방향으로 외란을 줍니다.
  '미소 외란 자동'을 끄면 P > P<sub>cr</sub>에서도 곧은(불안정) 평형이 유지되다가 외란 한 번에 좌굴하는 모습을 볼 수 있습니다.
- 각 창의 **−/+** 버튼으로 최소화하고, 창 아래의 **손잡이(━)** 를 끌어 높이를, 열 사이의 **⋮** 손잡이로 폭을 조절할 수 있습니다.

## 계산 방식

- **임계하중·모드 형상:** Euler–Bernoulli 보 요소의 선형 좌굴 고유치 해석(FEM, (K − P·K<sub>G</sub>)φ = 0)
- **후좌굴:** 정확한 곡률식(θ′ = M/EI)을 사격법(shooting)과 진폭 제어 연속해법으로 풀어 평형경로를 구함
  (양단 핀 elastica의 타원적분 정해와 일치). 후좌굴 경로에 최대 하중(극한점)이 있는 지지조건은 그 점까지만 표시합니다.
- **동적 거동:** 1차 모드 단일 자유도 모델 (정성적인 시간 스케일)

인터넷 연결이 필요합니다 (Tailwind CSS, KaTeX, Font Awesome을 CDN에서 불러옵니다).
